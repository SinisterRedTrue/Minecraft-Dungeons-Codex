# Data audit (Prompt 13)

Method: `npx tsx scripts/dev/audit.ts audit-20261113 20 all`. For each game, 20 entities are picked with a seeded shuffle (two per category, then one more for the first four), excluding the entities earlier spot checks covered (seed 20261112). The live wiki page of each entity is fetched fresh (not from the sync cache) and every string and number of the entity is searched for in the page text. Misses were then judged by hand with `scripts/dev/peek.ts`. The raw output is in `data-audit-raw.txt` (run before the fix below).
